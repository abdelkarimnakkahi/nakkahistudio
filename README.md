# Portfolio Website

## Overview  
This is my personal portfolio website showcasing my skills, projects, and contact information.

## Technologies Used  
- HTML  
- CSS  
- JavaScript

## Features  
- Responsive design for mobile and desktop  
- Simple animations to enhance user experience  
- Project showcase with links and descriptions  
- Contact information provided (no contact form)

## Setup Instructions  
1. Clone the repository  
2. Open `index.html` in a browser to view the site

## Deployment  
Hosted on [Netlify](https://www.netlify.com/) at https://nakkahistudio.netlify.app/
